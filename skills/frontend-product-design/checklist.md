# Frontend Product Design Checklist

## Intake
- [ ] Intent and success criteria captured
- [ ] Constraints (stack, design system, brand, timeline) recorded
- [ ] Existing design docs / Figma / prior research located or noted as missing

## Research (before design doc)
- [ ] Comparable large-system solutions identified
- [ ] Trade-offs, failure modes, and constraints recorded with sources
- [ ] Direction chosen only after research notes exist

## Design Document
- [ ] Problem, goals, non-goals stated
- [ ] Proposed solution and alternatives considered
- [ ] Design-system impact described
- [ ] Accessibility considerations listed
- [ ] Performance considerations listed
- [ ] UX writing / microcopy needs listed
- [ ] Usability risks and edge cases listed
- [ ] Open questions explicitly called out
- [ ] Document revised until major ambiguities are gone

## Milestones
- [ ] Work split into ordered, reviewable milestones
- [ ] Each milestone has clear acceptance criteria
- [ ] First milestone is the smallest useful slice

## Discipline Pass
- [ ] Design systems / component reuse checked
- [ ] Accessibility (keyboard, SR, contrast, focus, ARIA) checked
- [ ] Performance (CWV, load, runtime) checked
- [ ] UX writing quality checked
- [ ] Usability / cognitive load checked

## Evidence
- [ ] Evidence pack produced
- [ ] No target-project mutation performed
- [ ] Status is complete / partial / failed / blocked with reasons
